# Drone-view aerial photography dataset for highway surface debris detection: VOC+Y

## Body

Drone-view aerial photography dataset for highway surface debris detection in VOC+YOLO format with 2133 images in one category
Warm reminder: Due to the dataset's replicability, please confirm compliance before purchasing.
Dataset format: Pascal VOC format + YOLO format (txt file without split path, only contains jpg images and corresponding VOC format xml files and yolo format txt files)
Number of images (number of jpg files): 2133
Number of annotations (number of xml files): 2133
Number of annotations (number of txt files): 2133
Label category count: 1
Annotation category name: ["scatter"]
Number of boxes labeled in each category

Number of scatters = 25910
Total number of scatters: 25910
Number of images per category occupied by a scatter
Number of images occupied by a scatter = 2133
Image resolution: 1920x1080
Labeling tool used: labelImg
Labeling rules: Draw a rectangle around the category.
Important note: The dataset does not have separate training, validation, and test sets; you need to partition them yourself.
Special declaration: This dataset does not guarantee the accuracy of the trained models or weight files.
